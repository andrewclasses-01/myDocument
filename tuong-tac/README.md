# tuong-tac/ — nội dung tương tác

Mô phỏng, trò chơi nhỏ, bài thực hành HTML (không phải game chấm điểm — game chấm điểm ở AWord).
Mỗi mục: `tuong-tac/<nhom>/<ma>/index.html` + `meta.json`. Dùng được cảm ứng (bảng tương tác TOMKO), nút ≥ 44 px.
Tạo mới: `node tools/tao.js tuong-tac <nhom> <ma> "Tên"`.
